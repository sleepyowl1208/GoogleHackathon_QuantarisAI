# EvidenceDrawer
The rigorous side panel behind every number: each claim with its kind, source and confidence.

**Provide:** `title` (the number being explained), `items` (`{kind, claim, source?, confidence?: 0–1}`), optional `onClose`.

- Neutral by design: white panel, ink text, EvidenceTags carry the kind. No brand fills, no green — credibility over decoration.
- Order items as reasoning flows: facts → assumptions → calculations → simulations → inferences → recommendation.
- Sources in mono; confidence as five ticks with an accessible "n of 5" label.
- Demo sources must say they are illustrative.
