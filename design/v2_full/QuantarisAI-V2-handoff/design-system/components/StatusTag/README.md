# StatusTag
The semantic colour language in its smallest form: each tone is a colour PLUS a glyph PLUS a word.

**Provide:** `tone` and a short label.

| tone | colour | glyph | means |
|---|---|---|---|
| `opportunity` | saffron | ↗ | economic opportunity, selected path |
| `system` | blue | ◉ | system data, AI activity, information |
| `positive` | green | ✓ | recovered, reduced, saved, viable |
| `assumption` | amber, dashed | ≈ | uncertain input, needs review |
| `risk` | red | ▲ | environmental risk, failure, hard constraint |
| `inactive` | grey | ○ | unavailable, unknown |

- Never use `positive` for a merely "done" step — green is reserved for beneficial outcomes.
- The dashed border is what tells `assumption` apart from saffron; never remove it.
