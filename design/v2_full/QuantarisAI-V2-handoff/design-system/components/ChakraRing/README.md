# ChakraRing
The 24-segment radial progress — the system's quiet Ashoka-Chakra signature.

**Provide:** `value` (0–1) or `spinning`, optional `tone` (`system` default blue | `positive` | `opportunity`), `size`, `showValue`, `caption`, `label`.

- 24 segments = 24 hours of a running system; progress fills clockwise from 12 o'clock.
- `spinning` steps one segment at a time (no smooth spin, no glow) and stops under reduced motion.
- Use `positive` only for circularity/sustainability scores; scenario progress stays blue.
- Never enlarge it into a background motif.
