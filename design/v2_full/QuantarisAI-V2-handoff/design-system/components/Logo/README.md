# Logo
The QuantarisAI mark and lockup: an open Q-loop around a 24-spoke hub, with a saffron flow tail leaving through the gap.

**Provide:** `size` (px height of the mark; the wordmark scales with it), `variant` (`full` | `mark`), `tone` (`default` | `reverse` for `nav-surface` / `ashoka` grounds), optional `descriptor` ("Industrial Intelligence" on the Command Center only).

- Below 32px the component drops the spokes automatically (same rule as `qai-mark-small.svg`).
- The wordmark is set in the `display` family: "Quantaris" bold, "AI" medium, one word, never spaced or hyphenated.
- In the dark theme the default tone switches its ink automatically; use `reverse` only on navy fills in the light theme.
- Do: one logo per screen, top-left in `AppNav`. Don't: recolour the tail green, put the mark on saffron, animate it beyond the loader, or pair it with an Indian flag.
