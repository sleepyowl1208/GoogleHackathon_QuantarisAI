# EvidenceTag
The six epistemic kinds, told apart by glyph and border style first and colour second.

**Provide:** `kind` (`fact` | `assumption` | `calculation` | `inference` | `simulation` | `recommendation`); children override the label.

- FACT ■ solid ink border · ASSUMPTION ◇ dashed amber · CALCULATION Σ blue · INFERENCE ◐ dotted muted · SIMULATION ∿ double-rule blue · RECOMMENDATION → saffron outline.
- Always mono uppercase. Never filled — evidence must look like annotation, not decoration.
- Put one next to every number a person might act on (see `MetricTile` `evidence`).
