# LevelPath
Where you are in the zoom stack: INDIA › REGION › ECOSYSTEM › FACTORY › PROCESS › EVIDENCE.

**Provide:** `current` (index), `onSelect(index)`, optional `levels`, `free` (allow jumping ahead).

- Sits top-left over every spatial screen. The current level is the `ashoka` fill.
- Moving down a level is a camera move into the selected object (600–900ms, `--qa-ease-flow`), never a page swap.
