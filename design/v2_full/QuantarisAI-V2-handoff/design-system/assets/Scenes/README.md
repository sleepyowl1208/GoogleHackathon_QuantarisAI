# Scenes

2× reference renders (3200 × 2000) of the spatial layer, made from the live scene kit — the visual target for engineering and QA, and ready for slides. All data shown is illustrative.

- `ecosystem-scene.png` / `ecosystem-scene-dark.png` — Living Industrial Ecosystem, complete: farms, spinning mill, Tiruppur unit (saffron ring), solar + grid, water recovery, workforce, warehouse + port, offcuts, mechanical recycling and Factory B on green rings.
- `factory-twin.png` / `factory-twin-dark.png` — Generative Factory Twin cutaway, Cutting selected, offcuts recovered along the green path.
- `india-intelligence-map.png` / `india-intelligence-map-dark.png` — physical India map (no land frontiers drawn), candidate columns by suitability, Tiruppur recommended, supply/export arcs, renewable parks, constraint zones, green circular link to Panipat.
- `flow-material.png`, `flow-energy.png`, `flow-water.png`, `flow-waste.png`, `flow-circular.png` — one flow layer each, buildings ghosted to 22%.
- `ecosystem-expansion.png` — dark: waste → recovery → secondary material → Factory B (factory-to-factory connection).
- `construction-1-supply.png`, `construction-2-resources.png`, `construction-3-complete.png` — three frames of the scenario materialising.

Use them as images only; never as the live product surface. Regenerate them when the scene kit or the scene tokens change.
