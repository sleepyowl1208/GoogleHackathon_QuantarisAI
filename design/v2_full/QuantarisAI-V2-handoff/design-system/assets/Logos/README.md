# Logos

The QuantarisAI mark: an open loop (the Q, and a resource cycle) around a 24-spoke hub, with a flow tail leaving through the gap and ending in a node — material leaving a system and becoming opportunity.

- `qai-mark.svg` — full-colour mark for light grounds (`surface`, `surface-raised`). Ring, spokes and hub in `ashoka` (#0B1733); tail and node in `saffron-strong` (#DD6F00). Use at 32px and above.
- `qai-mark-reverse.svg` — full-colour mark for dark grounds (`nav-surface`, dark theme `surface`). Ring and hub #EDF1F7, spokes #A4AEC2, tail #F59A3C.
- `qai-mark-mono.svg` — single ink #101A2E (`ink`), for one-colour print, embossing and fax-grade documents. `<img>` cannot recolour it; on dark grounds use the reverse file.
- `qai-mark-small.svg` — spokes removed and strokes thickened for 16–31px (favicon, tabs, table rows). Ink as `qai-mark.svg`.
- `qai-app-icon.svg` — app/favicon tile: `ashoka` rounded square (radius 14 of 64) carrying the reverse mark.

Clear space around the mark: one hub-width (¼ of the mark's height) on every side. Never recolour the tail green, rotate the mark, add a glow, or place it on saffron.
