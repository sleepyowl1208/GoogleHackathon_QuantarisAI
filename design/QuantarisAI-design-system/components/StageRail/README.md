# StageRail
The scenario's unfolding: Ambition → Location → Factory → Economics → Environment → Waste → Circularity → Next opportunity.

**Provide:** `current` (index), optional `stages` (labels), `positive` (indexes of completed stages whose outcome was beneficial).

- Done stages are blue with ✓; the current stage is the saffron fill; upcoming stages are outlined.
- A completed stage turns green only when it produced a sustainability gain (e.g. Environment, Waste) — pass it in `positive`.
- Never reorder or rename stages per scenario.
