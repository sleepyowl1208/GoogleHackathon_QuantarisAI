# CircularityPath
The signature QuantarisAI moment: a neutral waste stream becomes a green pathway to value as the system discovers it.

**Provide:** `state` (`neutral` → `analysing` → `discovered`), `source`/`sourceSub`, `waste`/`wasteSub`, `steps` (recovery chain labels), `value`/`valueSub`, optional `discoveredText`.

- `neutral`: the waste is a dashed grey box; downstream steps are faint.
- `analysing`: the path becomes a moving blue dashed line (the system thinking) with a stepping `ChakraRing`.
- `discovered`: the line turns solid `green`, steps fill `green-soft` with ✓ one after another (150ms stagger), the value node fills green — WASTE → VALUE.
- Play it once per discovery; never loop it. Under reduced motion the change is instant.
- Only show `discovered` for a pathway that has evidence behind it.
