# MissionComposer
The Command Center's mission input: it should feel like initiating an industrial simulation, not chatting.

**Provide:** `defaultValue` or controlled `value` + `onChange`, `onSubmit(text)`, optional `params` (`{label, value}` chips for region, horizon, priority), `eyebrow`, `actionLabel` (default "Initiate simulation").

- The mission is typed in the `display` face at 22/30 — an ambition statement, not a chat message.
- The blue dot + "New industrial mission" eyebrow is the system layer; the saffron "Initiate simulation" is the only accent.
- No chat bubbles, no avatar, no "Ask anything". Place it centred under the `Logo` with descriptor, with `space-7` above.
