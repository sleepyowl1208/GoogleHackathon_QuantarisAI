# QuantarisAI

The current frontend is a deterministic, fixture-backed Vertical Slice 1. It does not use live AI, maps, authentication, databases, or cloud services.

Run it locally:

```sh
cd apps/web
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000). Run validation with `npm run typecheck`, `npm run lint`, `npm test`, and `npm run build`.
